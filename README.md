# 🎀 Meu Ateliê Mágico

App infantil de desenhar, colorir e brincar. É um único arquivo (`index.html`), sem instalação.

**Brincadeiras:** desenhar, colorir (11 desenhos), vestir a princesa, cupcake, jardim, jogo da memória e estourar bolhas.

## Como publicar no GitHub Pages
1. Crie um repositório no GitHub e envie `index.html` e este `README.md`.
2. Vá em **Settings → Pages**.
3. Em **Branch**, escolha `main` e a pasta `/ (root)`, e clique em **Save**.
4. Depois de um minuto, o site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

Também funciona abrindo o `index.html` direto no navegador.
